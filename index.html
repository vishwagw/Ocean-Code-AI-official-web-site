Drones that navigate by sight alone.

FromSky is a vision-only autonomous navigation SDK for commercial drones — perception, planning and obstacle avoidance from a single camera. No GPS. No IMU. No LiDAR.

What FromSky does

Autonomy that doesn't depend on signals you might lose.

GPS drops indoors, under bridges, in urban canyons and in contested airspace. FromSky navigates from the camera feed itself — so it keeps working where signal-based systems stop.

Vision-only perception

Visual SLAM, monocular depth and optical flow fuse into a live estimate of where the drone is and what's around it — from one camera.

Plans and avoids in real time

An occupancy map drives global and local planning with active collision avoidance, producing velocity commands frame by frame.

Integrates in three lines

A clean Python SDK that outputs standard MAVLink velocity setpoints. Read the result, send it to your flight controller — done.

The pipeline

One camera frame in. A navigation command out.

Every frame runs the full perception-to-control loop. Each stage hands off to the next, and the system degrades gracefully when any single signal weakens.

Built for the hardware you already fly

Optimised for NVIDIA Jetson.

FromSky is designed to run on the Jetson companion computers commercial drone platforms already carry — putting the perception pipeline on the GPU where it belongs.

Edge-native

Runs onboard. No cloud round-trip, no dependency on a connection in the air.

Hardware-agnostic SDK

Camera and flight-controller abstraction layer adapts to your platform and your MAVLink stack.

Designed-in safety

Graceful degradation and active braking when perception confidence drops or an obstacle gets too close.
